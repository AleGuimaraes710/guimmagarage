# Página do link da bio

Site publicado em https://guimmagarage.netlify.app (Netlify).

- `index.html`: página principal. Grupos, ofertas especiais e os botões de "Meus produtos". Para editar, procure o bloco "ÁREA PRA EDITAR".
- `produtos.html`: as subpáginas de produtos (`?p=trilha`, `?p=klx450`, `?p=wideband`, `?p=3d`, `?p=crf250`). Para editar, procure o bloco "ÁREA PRA EDITAR".
- `img/`: logos e fotos.

Itens marcados `exemplo: true` ficam escondidos no site publicado.

## Como publicar

Este repositório é público e está ligado ao Netlify (projeto `guimmagarage`). Cada merge na branch `main` publica o site sozinho em cerca de 1 minuto.
